ขั้นที่ 3 จาก 7

ติดตั้ง AI agent

⚠️ ยังไม่ได้ทดสอบ · ผู้เขียนตรวจชื่อแพ็กเกจจาก npm เมื่อ 2026-10-29 (claude-code 2.1.312, codex 0.165.0, gemini-cli 0.66.0) แต่ยังไม่ได้ติดตั้งบนเครื่องสะอาด

AI agent คือ AI ที่ทำงานใน terminal ได้ อ่านไฟล์ พิมพ์คำสั่ง และใช้ skills ของ Oracle ได้ ซึ่งแชตผ่านเว็บทำไม่ได้

เลือกตัวไหนก็ได้

คู่มือนี้ไม่บังคับ ใช้ตัวที่คุณมีบัญชีอยู่แล้ว ส่วน skills ของ Oracle รองรับทั้งสามตัวนี้ (ทดสอบการติดตั้งไฟล์แล้ว ดูหน้า 6)

ขั้นที่ 1: ติดตั้ง Node.js

ดาวน์โหลดจาก nodejs.org เลือกรุ่น LTS แล้วเปิด terminal ใหม่ จากนั้นเช็ก:

node --version

ขั้นที่ 2: ติดตั้ง agent สักตัว

Claude Code

npm install -g @anthropic-ai/claude-code

เริ่มใช้: พิมพ์ claude

Codex CLI

npm install -g @openai/codex

เริ่มใช้: พิมพ์ codex

Gemini CLI

npm install -g @google/gemini-cli

เริ่มใช้: พิมพ์ gemini

ครั้งแรกแต่ละตัวจะให้ล็อกอิน ทำตามหน้าจอ เงื่อนไขและค่าใช้จ่ายของแต่ละเจ้าให้ดูจากหน้าทางการของเขา คู่มือนี้ไม่ได้ตรวจให้

มีวิธีติดตั้งแบบอื่นด้วย เช่น ตัวติดตั้งทางการของแต่ละเจ้า ถ้าคำสั่ง npm ข้างบนใช้ไม่ได้ ให้ค้นหน้าทางการของ agent ที่เลือก หรือใช้กล่องถาม AI ในหน้า 7
