ขั้นที่ 3 จาก 7

ติดตั้ง AI agent

⚠️ ยังไม่ได้ทดสอบ · ผู้เขียนตรวจชื่อแพ็กเกจ npm ของ Claude Code (2.1.312) และ Codex (0.165.0) และตรวจว่า URL ติดตั้ง agy ของ Google ตอบ HTTP 200 เมื่อ 2026-10-29 แต่ยังไม่ได้ติดตั้งตัวใดบนเครื่องสะอาด

AI agent คือ AI ที่ทำงานใน terminal ได้ อ่านไฟล์ พิมพ์คำสั่ง และใช้ skills ของ Oracle ได้ ซึ่งแชตผ่านเว็บทำไม่ได้

เลือกตัวไหนก็ได้

คู่มือนี้ไม่บังคับ ใช้ตัวที่คุณมีบัญชีอยู่แล้ว ส่วน skills ของ Oracle รองรับทั้งสามตัวนี้ (ทดสอบการติดตั้งไฟล์แล้ว ดูหน้า 6) ตัวที่ใช้ Node.js ติดตั้งคือ Claude Code และ Codex ส่วน Antigravity ไม่ต้องใช้ Node.js

ขั้นที่ 1: ติดตั้ง Node.js

ดาวน์โหลดจาก nodejs.org เลือกรุ่น LTS แล้วเปิด terminal ใหม่ จากนั้นเช็ก:

node --version

ขั้นที่ 2: ติดตั้ง agent สักตัว

Claude Code

npm install -g @anthropic-ai/claude-code

เริ่มใช้: พิมพ์ claude

Codex CLI

npm install -g @openai/codex

เริ่มใช้: พิมพ์ codex

Antigravity CLI (คำสั่ง agy) — ตัวที่ Google ใช้แทน Gemini CLI

Mac / Linux

curl -fsSL https://antigravity.google/cli/install.sh | bash

Windows (PowerShell)

irm https://antigravity.google/cli/install.ps1 | iex

เริ่มใช้: พิมพ์ agy ไม่ต้องติดตั้ง Node.js สำหรับตัวนี้

Gemini CLI เดิมใช้ไม่ได้แล้วสำหรับบัญชีส่วนตัว เนื้อหานี้มาจากบทความภายนอกหลายแห่งที่ผู้เขียนค้นเมื่อ 2026-10-29 (ระบุว่า Google ยุติให้บัญชีส่วนตัวใช้ Gemini CLI ตั้งแต่ 18 มิ.ย. 2026) ไม่ใช่จากประกาศของ Google โดยตรง และผู้เขียนยืนยันได้แค่ว่าเครื่องของผู้เขียนมี agy เวอร์ชัน 1.4.3 ใช้งานอยู่ ถ้าคุณมีบัญชี Google องค์กร ให้ตรวจสิทธิ์กับหน้าทางการของ Google

ครั้งแรกแต่ละตัวจะให้ล็อกอิน ทำตามหน้าจอ เงื่อนไขและค่าใช้จ่ายของแต่ละเจ้าให้ดูจากหน้าทางการของเขา คู่มือนี้ไม่ได้ตรวจให้

มีวิธีติดตั้งแบบอื่นด้วย เช่น ตัวติดตั้งทางการของแต่ละเจ้า ถ้าคำสั่งข้างบนใช้ไม่ได้ ให้ค้นหน้าทางการของ agent ที่เลือก หรือใช้กล่องถาม AI ในหน้า 7
