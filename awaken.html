ปลุก Oracle ของตัวเอง

✅ ทดสอบแล้ว · Ubuntu 24.04 (Linux x86_64) · bun 1.3.14 · arra-oracle-v3 26.7.26-alpha.227 · arra-oracle-skills-cli 26.8.23-alpha.2112 · 2026-10-29 · ทดสอบเฉพาะการติดตั้งไฟล์ skills ว่ามี awaken ครบ ส่วนการพิมพ์ /awaken ใน agent จริงและการสร้าง Oracle ยังไม่ได้ทดสอบ

หน้านี้ไม่บังคับ ทำเมื่อจบหน้า 5 แล้ว Oracle คือผู้ช่วยที่มีตัวตนและความจำของตัวเอง

ขั้นที่ 1: ติดตั้ง skills ให้ agent ของคุณ

เลือกบรรทัดที่ตรงกับ agent ที่ติดตั้งในหน้า 3 แล้วรันใน terminal

Claude Code

bunx --bun github:Soul-Brews-Studio/arra-oracle-skills-cli#alpha install -g -y -p standard --agent claude-code

Codex CLI

bunx --bun github:Soul-Brews-Studio/arra-oracle-skills-cli#alpha install -g -y -p standard --agent codex

Gemini CLI

bunx --bun github:Soul-Brews-Studio/arra-oracle-skills-cli#alpha install -g -y -p standard --agent gemini
ระวังชื่อ Gemini: README ของ skills เขียน --agent gemini-cli แต่ตอนทดสอบ ตัวติดตั้งตอบว่า Unknown agents: gemini-cli และรับชื่อ gemini แทน จึงใช้ชื่อนี้ในคู่มือ

ผลที่ทดสอบ: ทั้งสามตัวติดตั้งแล้วมีโฟลเดอร์ awaken ใต้โฟลเดอร์ skills ของแต่ละ agent (Claude Code: ~/.claude/skills, Codex: ~/.codex/skills และ ~/.codex/prompts, Gemini: ~/.gemini/skills และ ~/.gemini/commands)

ขั้นที่ 2: ปิดแล้วเปิด agent ใหม่

ตัวติดตั้งแจ้งว่า "Restart your agent to activate skills" ให้ปิด agent แล้วเปิดใหม่ (พิมพ์ claude, codex หรือ gemini)

ขั้นที่ 3: เรียก awaken

ใน agent พิมพ์ /awaken คำอธิบายของ skill ระบุว่าแบบเต็มใช้เวลาราว 20 นาที และมีแบบเร็ว --fast ราว 5 นาที ผู้เขียนยังไม่ได้ลองรันจริง จึงไม่รู้ว่าแต่ละ agent เรียกด้วยพิมพ์แบบเดียวกันหรือไม่ ถ้าไม่ขึ้น ให้ถาม AI ด้วยข้อความจากหน้า 7

ทางเลือกสำหรับ Claude Code

README ของ skills ระบุว่าใน Claude Code ติดตั้งได้โดยไม่ต้องมี bun หรือ git ด้วยคำสั่งสองบรรทัดนี้ (ยังไม่ได้ทดสอบ):

/plugin marketplace add Soul-Brews-Studio/arra-oracle-skills-cli
/plugin install oracle-skills@oracle-skills
