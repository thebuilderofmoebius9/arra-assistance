ARRA กับ Oracle คืออะไร

หน้านี้เล่าภาพรวมสั้น ๆ ก่อนลงมือ อ่านจบใน 2 นาที

ARRA คืออะไร

ARRA คือโปรแกรมความจำที่รันในเครื่องของคุณเอง ทำหน้าที่เหมือนสมุดจดที่ค้นหาได้ คุณจดความรู้ลงไป แล้วค้นกลับมาดูภายหลังได้ แม้ปิดเครื่องแล้วเปิดใหม่

Oracle คืออะไร

Oracle คือผู้ช่วย AI ที่มีตัวตนของตัวเอง และใช้ ARRA เป็นความจำ ผู้ช่วยแชตทั่วไปอาจไม่เก็บสิ่งที่คุณสอนไว้ข้ามบทสนทนา ส่วน Oracle จดสิ่งที่เรียนรู้ลง ARRA และค้นกลับมาใช้ได้

เส้นทางของคู่มือนี้

  1. เปิด terminal — หน้าต่างพิมพ์คำสั่ง (ไม่ต้องเขียนโปรแกรมเป็น)
  2. ติดตั้ง AI agent — Claude Code, Codex หรือ Gemini เลือกตัวไหนก็ได้ (ใช้ตัวที่คุณมีบัญชีอยู่แล้ว)
  3. ติดตั้ง ARRA และเช็กว่าทำงาน
  4. จดความรู้แรก แล้วค้นกลับมาเจอ — นี่คือเส้นชัยของการติดตั้ง
  5. ปลุก Oracle ของตัวเอง — ทำต่อได้ ไม่บังคับ
  6. ติดแล้วทำอย่างไร — ข้อความที่ก๊อปไปถาม AI ของคุณได้ และ error ที่เจอบ่อย
ใช้ AI ผ่านเว็บหรือแอปอยู่แล้วใช่ไหม ไม่เป็นไร คุณไม่ต้องเลิกใช้ ทุกหน้ามีกล่อง "ติดตรงไหน" ให้ก๊อปข้อความไปถาม AI ที่คุณใช้อยู่ได้ มันช่วยอ่าน error ให้คุณ
