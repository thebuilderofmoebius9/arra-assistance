ติดตั้ง ARRA

✅ ทดสอบแล้ว · Ubuntu 24.04 (Linux x86_64) · bun 1.3.14 · arra-oracle-v3 26.7.26-alpha.227 · arra-oracle-skills-cli 26.8.23-alpha.2112 · 2026-10-29 · ขั้น 0 (ติดตั้ง bun เอง) และ Windows ยังไม่ได้ทดสอบ

หน้านี้ติดตั้ง ARRA และเช็กว่าทำงาน ต้องเปิด terminal 2 หน้าต่าง

ขั้นที่ 0: ติดตั้ง bun

bun เป็นตัวรันที่ ARRA ใช้ ผู้เขียนทดสอบกับ bun 1.3.14 ที่ติดตั้งไว้แล้ว ส่วนคำสั่งติดตั้ง bun ข้างล่างมาจากหน้า bun.sh และยังไม่ได้ลองบนเครื่องสะอาด

Mac / Linux

curl -fsSL https://bun.sh/install | bash

Windows (PowerShell)

powershell -c "irm bun.sh/install.ps1 | iex"

ปิด terminal แล้วเปิดใหม่ จากนั้นเช็ก:

bun --version

ขั้นที่ 1: เปิดเซิร์ฟเวอร์ ARRA (หน้าต่างที่ 1)

bunx --bun --package github:Soul-Brews-Studio/arra-oracle-v3 arra-oracle

ครั้งแรกจะดาวน์โหลดสักครู่ จากนั้นเห็นบรรทัดคล้ายนี้ (ในการทดสอบ เปิดที่พอร์ต 47990 ของเครื่องทดสอบ ส่วนค่าปกติตามเอกสารคือ 47778):

🔮 Arra Oracle HTTP server → http://localhost:47778

เปิดหน้าต่างนี้ค้างไว้ ถ้าปิด เซิร์ฟเวอร์จะหยุด

ขั้นที่ 2: เช็กสุขภาพ (เบราว์เซอร์)

เปิดเบราว์เซอร์ไปที่ http://localhost:47778/api/health ต้องเห็นข้อความที่มี "status":"ok" และ "oracle":"connected"

เห็น "healthStatus":"degraded" ไม่ต้องตกใจ ในการทดสอบ ค่านี้ขึ้นเพราะเครื่องไม่มีตัวสร้าง embedding (ข้อความเต็มคือ "no embedder configured/reachable — FTS5-only") แปลว่าค้นหาด้วยคำได้ แต่ยังไม่มีการค้นตามความหมาย ซึ่งไม่จำเป็นสำหรับคู่มือนี้

ขั้นที่ 3: ตรวจละเอียดด้วย doctor (หน้าต่างที่ 2)

เปิด terminal หน้าต่างใหม่ แล้วรัน:

bunx --bun --package github:Soul-Brews-Studio/arra-oracle-v3 arra-cli doctor

ผลที่ได้ในการทดสอบ (ตัดมาบางบรรทัด):

PASS backend reachable
WARN overall health — degraded; see subsystem detail
PASS DB writable
PASS FTS healthy
WARN vector backend — degraded: FTS-only
WARN embedder reachable — degraded: FTS-only
PASS plugins loaded
PASS MCP launchable

ผ่านเกณฑ์ คือไม่มีบรรทัดขึ้นต้นด้วย FAIL บรรทัด WARN เรื่อง vector/embedder เป็นเรื่องปกติ

ข้อมูลของคุณเก็บที่ไหน: ตามเอกสารของ ARRA ค่าเริ่มต้นคือโฟลเดอร์ ~/.oracle ผู้เขียนทดสอบโดยกำหนดโฟลเดอร์ชั่วคราวแยกต่างหาก จึงยังไม่ได้ยืนยันค่าเริ่มต้นนี้
