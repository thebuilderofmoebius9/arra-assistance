ทางที่ 2: error ที่เจอบ่อย

bun: command not found

ปิด terminal แล้วเปิดใหม่ ถ้ายังไม่หาย README ของ ARRA แนะนำ (Mac/Linux): export PATH="$HOME/.bun/bin:$PATH" (มาจาก README ยังไม่ได้ทดสอบ)

เปิด /api/health แล้วเห็น "healthStatus":"degraded"

ปกติ ถ้าสาเหตุคือไม่มี embedder ดูหน้า 4 ขั้นที่ 2

doctor ขึ้น FAIL ว่า "missing from /api/health subsystem detail"

ผู้เขียนเจอบนเครื่องของตัวเอง เพราะเซิร์ฟเวอร์ที่เปิดค้างไว้เป็นเวอร์ชันเก่า (26.6.1-alpha.1506) แต่ตัว CLI เป็นเวอร์ชันใหม่ (26.7.26-alpha.227) พอเปิดเซิร์ฟเวอร์เวอร์ชันใหม่บนเครื่องสะอาด doctor ไม่ขึ้น FAIL แล้ว ถ้าคุณเจอ ให้ปิดเซิร์ฟเวอร์เก่าแล้วเปิดใหม่ด้วยคำสั่งในหน้า 4

Unknown agents: gemini-cli

ใช้ --agent antigravity (หรือ --agent gemini ถ้ายังใช้ Gemini CLI เดิม) ดูหน้า 6

ค้นภาษาไทยแล้วไม่เจอ

ดูข้อควรระวังท้ายหน้า 5 ลองพิมพ์วลีให้ยาวขึ้น หรือบันทึกคำสำคัญเป็นภาษาอังกฤษควบ

ยังไม่หาย

รวบรวมข้อมูลตามกล่องข้อความด้านบน (ขั้นไหน, ระบบอะไร, คำสั่ง, error) แล้วส่งให้ผู้ดูแลที่ส่งลิงก์คู่มือนี้ให้คุณ ข้อมูลครบทำให้ช่วยได้เร็วขึ้นมาก
